# sena-flyer-prompt

スマートフォンで画像生成用プロンプトの JSON を編集する静的 Web アプリです。外部ライブラリやサーバー処理は使いません。入力データはブラウザの `localStorage` に保存されます。

項目と配列要素は同じ階層内で上下に並べ替えられます。画面下の「戻す」は直前のデータ編集を取り消します（履歴はページを閉じると消えます）。

最上位の「用途」「タイトル」「参考画像」「デザイン」「内容」「厳守」は固定です。値と内部の項目は編集できます。読み込むJSONにもこの6項目と元のデータ型が必要です。

## ローカル起動

```sh
python3 -m http.server 8000
```

`http://localhost:8000` を開いてください。Vercel ではリポジトリをそのまま静的サイトとして公開できます。
